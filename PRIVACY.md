# Privacy policy

RoxaZip does not collect, store, transmit or share personal data.

* **No network access.** The program has no update checker, no telemetry, no
  analytics and no advertising. It does not connect to the internet.
* **Local processing only.** Archives are opened, created and extracted on the
  user's own computer.
* **Settings stay local.** The configuration is written to the user's own
  registry key (`HKCU\Software\RoxaZip`), and the file history and panel
  settings belong to the Windows user profile. Nothing is uploaded; deleting the
  program and its settings removes them.
* **Microsoft Store version.** The package contains the same program without any
  additional data collection by us. Installation, updates and crash reports are
  handled by the Store itself, under
  [Microsoft's privacy statement](https://privacy.microsoft.com/).

Questions about this policy, or a request to delete data: open an issue at
<https://github.com/imacte/RoxaZip/issues>.

RoxaZip is based on 7-Zip and the 7-Zip ZS fork; the licenses of the program and
of the bundled libraries are listed in [COPYING](COPYING) and
[DOC/License.txt](DOC/License.txt).
